# Contributing

Thanks for helping improve this PlayStation 2 setup guide.

## Submitting a correction or test report

Please include:

1. PS2 model (for example, `SCPH-50004`) and region.
2. Boot method (FMCB, FHDB, disc exploit, other).
3. Memory-card hardware and firmware revision (if used).
4. Network/SATA adapter make and revision (if used).
5. HDD model, capacity, logical sector size and layout (APA, MBR/exFAT, GPT/exFAT).
6. RiptOPL edition, exact build identifier or commit, and core (native OPL / Neutrino).
7. Exact results, errors, screenshots with personal details removed, and whether a stock OPL build behaves differently.

Mark claims as **Documented upstream**, **Reported**, or **Hardware tested**. Avoid claiming that a feature works on all PS2 revisions because it works on one setup.

## Privacy and rights

Never attach console-unique files, passwords, keys, copyrighted game images, proprietary BIOS dumps or another person's saves. Do not place private backups in Issues or Pull Requests.

## Formatting

- Write in plain English with short numbered procedures.
- Put a warning **before** irreversible steps.
- Include original source links rather than copying entire upstream documents.
- Keep `README.md` concise and write hardware-specific instructions in `docs/`.
